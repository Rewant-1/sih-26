# Karmasarthi — Universal UI Rules

1. **UI Only:** Work strictly on UI/front-end design; never modify, fix, redesign, or interfere with backend functionality or logic.

2. **Government Platform:** Karmasarthi is a government platform and must maintain a clean, professional, trustworthy, spacious, and institutional visual language aligned with the Karmayogi ecosystem.

3. **Design Identity:** Karmasarthi should feel like a redesigned extension of Karmayogi, not a generic AI/EdTech website, while still having its own modern identity.

4. **Colors:** Use only the provided color palette, with Dusty Blue, Deep Navy, Slate Blue, Warm Ivory, and Stone Gray as the major colors and Saffron Gold only for highlights; never use gradients or dark themes.

5. **Typography & Symbols:** Never use Times New Roman, emojis, AI symbols, decorative symbols, or AI-generated-looking visual elements anywhere.

6. **Header & Navigation:** Maintain the exact same white header and capsule-style navbar across every page, using`karmasarthi.png` and keeping the navigation consistent.

7. **No Box-Card UI:** Do not create repetitive box-based card layouts, excessive bordered containers, static rectangular blocks, or generic dashboard-style cards; use spacious, structured layouts with strong visual hierarchy instead.

8. **No Div-Based Design:** Do not create UI that feels like a collection of arbitrary divs or disconnected containers; every element must have a clear purpose, hierarchy, alignment, and relationship with surrounding content.

9. **Consistency:** Every page must follow the same design system, including typography, spacing, colors, components, navigation, alignment, visual hierarchy, and interaction patterns, with no clutter.

10. **No Unnecessary Effects:** Never use hover animations, excessive decoration, or AI-style effects; creativity and animation are allowed only when they remain subtle, purposeful, professional, and consistent with a government platform.
